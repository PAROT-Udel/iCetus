## Project Overview

This project focuses on iCetus, which is built on top of the Cetus source-to-source compiler, integrated with the CaRV tool and the OpenAI API to enhance the capabilities of parallelization and optimization in scientific computing. iCetus is an advanced tool designed to involve users in the optimization process, allowing for manual, automated, and AI-assisted optimizations. The integration with CaRV provides a robust framework for verifying the correctness and performance of these optimizations, while the OpenAI API leverages advanced AI models to suggest code optimizations.


### Integrated Tools
**Cetus:**
  - Transforms sequential C code into parallel code for improved performance using OPenMP directives.
  - Applies various optimization techniques.

**CaRV:**
  - Assesses optimized code for correctness and performance.
  - Shortens Experimentation Time on code sections.

**OpenAI API:**
  - Provides AI-based code optimization insights.
